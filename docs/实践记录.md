# 实践记录

**简体中文** | [English](en/practice-log.md)

这里记录方法试行的事实与结论。目前尚无试行结果，已整理的文章不等于已经验证有效。

## 如何开始一次试行

1. 从选题清单选择一个具体问题，说明当前表现与已有证据。
2. 明确试行范围、负责人、持续时间和预期观察，不同时改变太多因素。
3. 使用[实践复盘模板](../templates/实践复盘模板.md)建立单独记录，关联 Issue。
4. 试行结束后比较结果与成本，说明其他可能影响结果的因素。
5. 决定保留、调整或停止，并把结论反馈到对应文章。

所有公开证据必须符合[隐私政策](../PRIVACY.md)。

## 记录索引

有真实试行后，在此按日期添加记录链接、关联选题、状态和一句话结论。所有对外部来源、样本范围和数据口径的限制应写在对应记录中。
